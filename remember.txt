# OpenSource Compass - Deployment & Architecture Log

    - Resolved 500 Internal Server Errors caused by UnicodeEncodeErrors on Windows (Emoji-free logs).
    - Fixed path resolution and NameErrors in the analysis engine.
- **Documentation**:
    - Created a comprehensive `PROJECT_DOCUMENTATION.md` covering all modules, endpoints, and architectural decisions.

## Architecture Decisions
- **Storage**: All repos reside in the root `.temp_repos/` for persistence across sessions.
- **Analysis**: Medians are used for repo-level health summary to avoid outlier skewing.
- **Caching**: Caching is commit-aware. If the commit SHA changes, a re-analysis is triggered.

## Known Setup Requirements
- Run `pip install radon networkx` for the analysis engine.
- Create `analysis_cache` table in Supabase (SQL provided in documentation).
